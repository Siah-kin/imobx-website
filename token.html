Self-compounding

O token da IMOBX é um token self-compounding de financiamento da comunidade: suas taxas voltam para a comunidade que cresce em torno das casas da IMOBX.

Para que serve?

Cada negociação do token paga uma taxa que financia a comunidade que cresce em torno das casas. Ter o token é opcional.

Qualquer benefício para quem trava seus tokens será nomeado, com suas condições, antes de valer. O que o token faz pela comunidade é definido por quatro regras, os quatro V, mais abaixo nesta página.

Na proposta, as famílias se associam a uma cooperativa de moradia e não precisam comprar nem ter tokens. A IMOBX começa com uma a três famílias, cada uma com o seu próprio contrato de moradia. O token vem numa etapa posterior e fica separado desses contratos.

O que significa self-compounding?

A maioria dos projetos de token levanta recursos vendendo tokens a investidores antes do lançamento, ou criando tokens novos. A IMOBX não faz rodada antecipada e não cria tokens depois. O que os primeiros compradores pagam vai para o pool do token, e a renda do projeto com o token é a taxa paga cada vez que ele muda de mãos. A maior parte dessa taxa volta para o projeto, para salários, novas casas e o pool, e assim o projeto cresce com o que ele mesmo gera.

Para onde vai a taxa?

Cada vez que o token muda de mãos, 14% do valor é a taxa. Quando US$ 100 em tokens mudam de mãos, a taxa de US$ 14 se divide assim:

O pool é a reserva comum onde o token muda de mãos, e recebe US$ 4,90 de cada taxa de US$ 14. Quando a IMOBX coloca os recursos iniciais do pool, ela fica com três quartos dele, e essa parte da taxa vai para novas casas (US$ 3,67). O resto (US$ 1,23) vai para quem coloca seus próprios recursos no pool. Se o token abrir pela curva de venda da Arctide, os recursos dos primeiros compradores iniciam o pool, e essa parte da taxa vai para a Arctide; as novas casas recebem então a parte gerada pelos recursos que a própria IMOBX colocar.

Em que ele é diferente da maioria dos tokens?

Tokenomics são as regras de um token: quantos tokens existem, quem recebe uma parte e de onde vem a renda do projeto. Na maioria dos projetos, a equipe e os primeiros investidores ficam com uma grande parte dos tokens, e novos tokens são criados como recompensa. O token da IMOBX segue outras regras:

Tokenomics tradicionalO token da IMOBX
De onde vem a renda do projetoDos próprios tokens: as partes da equipe e dos primeiros investidoresDe uma taxa cada vez que o token muda de mãos
Quantos tokens existemMuitas vezes novos tokens são criados como recompensa, e cada token passa a representar uma parte menor1.000.000 de tokens, fixos. Nenhum é criado depois
O que a equipe recebeUma grande parte dos tokensNenhum token para a equipe
O que mantém o projeto de péA entrada constante de recursos de novos participantesA renda que a comunidade já ganhou, usada dentro de um orçamento que os membros aprovam
Para onde vai a rendaPrincipalmente para a equipe e os primeiros investidoresDe cada taxa de 14%: 45% para salários, 35% para o pool (a maior parte para novas casas), 20% para quem trava seus tokens

A IMOBX cria 1.000.000 de tokens, uma única vez. Três quartos ficam para o mercado quando o token abrir. O quarto restante fica reservado: 5% para parceiros, 5% para a operação, 5% para recompensas da comunidade, 5% para a governança e 3% para corretores, todos travados para sempre, além de 2% para custos jurídicos. A equipe não recebe tokens.

Quais quatro regras orientam os recursos da comunidade?

Sempre que pessoas juntam recursos, surgem as mesmas quatro perguntas, uma para cada regra abaixo. A IMOBX responde com quatro regras, os quatro V: Volume, Voto, Verificação e Vínculo. Elas são a razão de ser do token e valem para todos os recursos da comunidade.

Aviso importante

  • O token da IMOBX está planejado e ainda não foi emitido. Esta página descreve o desenho pretendido, que pode mudar antes do lançamento, à medida que as regras brasileiras para criptoativos forem definidas.
  • Esta página não é uma oferta nem um convite para comprar, nem uma recomendação financeira, jurídica ou fiscal. Nenhuma autoridade analisou ou aprovou este conteúdo.
  • O token não dá participação na IMOBX nem direito a qualquer casa, terreno ou pagamento das famílias. Os valores das taxas descrevem o desenho e não são pagamentos prometidos.
  • Depois de emitido, um criptoativo pode perder seu valor em parte ou totalmente, e pode ser difícil vendê-lo quando você quiser. Ele não tem a proteção do FGC nem de outro fundo de garantia, e uma falha no software ou a perda da chave da carteira pode fazer você perder os tokens para sempre.
  • Procure orientação independente antes de tomar qualquer decisão sobre o token.
