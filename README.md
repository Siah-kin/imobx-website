# IMOBX

IMOBX is preparing a rent-to-own housing project in Rio de Janeiro, with shared decisions and a possible financial token to help fund construction and growth. The legal form, property arrangements and investment rights remain under study.

The website explains the proposal and current evidence. It does not accept investments or process housing payments.

For changes to the website and its exports, see [AGENTS.md](AGENTS.md). The publication
build requires a current editorial review stored outside this public repository:
`python build_publication.py --copy-review /absolute/private/review.json`.
Use `python build_publication.py --preview` first to inspect local HTML; this leaves
existing PDF, PowerPoint and ZIP exports unchanged.
That check establishes review completeness and freshness; reader comprehension needs
separate feedback from the intended audience.
